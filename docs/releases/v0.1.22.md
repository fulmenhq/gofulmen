# gofulmen v0.1.22 – AppIdentity portable discovery

Release Date: 2025-12-18  
Crucible SSOT: v0.2.23

## Overview

This patch release closes a portability gap in `appidentity`: `.fulmen/app.yaml` can now be discovered even when the binary is executed from a working directory outside the repository tree.

## Key Changes

### AppIdentity discovery fallback

- Discovery still prioritizes (in order): context injection, explicit path, `FULMEN_APP_IDENTITY_PATH`, then ancestor search from `RepoRoot`/CWD.
- When the ancestor search fails with NotFound, discovery now also searches ancestors of the running executable directory (`os.Executable()`).
- If `FULMEN_APP_IDENTITY_PATH` is set (even to a missing path), it remains authoritative and fallback is skipped.

### Better not-found diagnostics

Not-found errors now include both the primary search trace and the executable-dir fallback trace to make deployments easier to debug.

### Cache semantics: no “cached NotFound”

Only successful identity loads are cached for the process lifetime; discovery errors are not cached so callers can recover after environment changes.

## Testing & Validation

- `go test ./... -count=1`
- `FULMEN_APP_IDENTITY_PATH=/definitely/missing.yaml go test ./appidentity -v -count=1`
