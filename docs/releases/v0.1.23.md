# gofulmen v0.1.23 – AppIdentity embedded identity fallback

Release Date: 2025-12-18  
Crucible SSOT: v0.2.24

## Overview

This patch release completes the App Identity portability contract for distributed artifacts: applications can embed `.fulmen/app.yaml` into the binary/package so identity-dependent commands work outside repository context.

## Key Changes

### AppIdentity embedded fallback

- Added `appidentity.RegisterEmbeddedIdentityYAML()` to register a compiled-in identity payload.
- Discovery uses the embedded fallback only after:
  1. explicit path, 2) `FULMEN_APP_IDENTITY_PATH`, and 3) filesystem discovery (CWD + optional executable-dir fallback) fail.

### Crucible sync

- Updated embedded Crucible assets and `go.mod` dependency to Crucible `v0.2.24`.

## Template guidance (Go)

Because `//go:embed` cannot embed files outside the module tree, templates should mirror `.fulmen/app.yaml` to an embeddable path, for example:

- `internal/assets/appidentity/app.yaml`

Then embed and register:

```go
//go:embed internal/assets/appidentity/app.yaml
var embeddedIdentity []byte

func init() {
    _ = appidentity.RegisterEmbeddedIdentityYAML(embeddedIdentity)
}
```
