# gofulmen v0.1.25 – goneat hook compatibility guard

Release Date: 2025-12-20  
Crucible SSOT: v0.2.26

## Overview

This patch release adds a lightweight guardrail to catch known `goneat hooks generate --with-guardian` template regressions (stray trailing braces and missing `noglob`) before they break developer workflows.

## Key Changes

### Hooks compatibility guard

- Added `make verify-hooks-compat` (`scripts/verify-hooks-compat.sh`) to detect:
  - stray brace patterns like `passed!"}` / `passed!}`
  - missing `set -f` (noglob) in generated bash hooks
- Added a temporary mitigation `scripts/fixup-hooks-noglob.sh` to inject `set -f` into generated hooks until upstream templates consistently include it.
- Wired `verify-hooks-compat` into `make check-all`.

### Crucible sync

- Updated embedded Crucible assets and `go.mod` dependency to Crucible `v0.2.26`.

## Recommended workflow after regenerating hooks

```bash
goneat hooks generate --with-guardian
# optional: goneat hooks install

./scripts/fixup-hooks-noglob.sh
make verify-hooks-compat
```

## Testing & Validation

- `make verify-hooks-compat`
- `make precommit`
