# gofulmen v0.1.27 – AppIdentity schema sync fix

Release Date: 2025-12-24  
Crucible SSOT: v0.2.27

## Overview

This patch release fixes an AppIdentity schema drift issue: gofulmen’s embedded schema (`appidentity/app-identity.schema.json`) was out of sync with Crucible SSOT, causing vendor validation to incorrectly reject real-world vendor IDs that begin with digits (e.g. `3leaps`, `37signals`).

## Key Changes

- Synced `appidentity/app-identity.schema.json` to match Crucible SSOT.
- Added drift guard test: `appidentity/schema_sync_test.go`.
- Updated `make sync` to refresh the embedded schema via `scripts/sync-appidentity-schema.sh`.

## Testing & Validation

- `go test ./appidentity -run TestEmbeddedAppIdentitySchemaMatchesCrucible -v`
