# gofulmen v0.1.29 – Crucible v0.3.0 sync + agentic roles adoption

Release Date: 2026-01-03  
Crucible SSOT: v0.3.0

## Overview

This release syncs gofulmen’s embedded Crucible SSOT assets to `v0.3.0` and updates `go.mod` to match.

It also completes gofulmen’s migration away from an identity-based agent scheme in favor of Crucible’s role-based agent interface. Evergreen governance docs now reference roles (`devlead`, `devrev`, `infoarch`, `secrev`) and standardized attribution (model + interface + role).

## Key Changes

- Synced Crucible SSOT assets to `v0.3.0` and updated `go.mod` to `github.com/fulmenhq/crucible v0.3.0`.
- Added the synced role catalog under `config/crucible-go/agentic/roles/`.
- Updated `AGENTS.md` and `MAINTAINERS.md` to remove identity-based agent naming and standardize on roles + attribution.
- Added `docs/development/adr/ADR-0008-agentic-roles-adoption.md` documenting the transition.
- Updated `Makefile` documented minimum `GONEAT_VERSION` to `v0.4.0`.
