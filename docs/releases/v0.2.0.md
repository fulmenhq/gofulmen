# gofulmen v0.2.0 – Native similarity algorithms for MIT-compatible SBOM

Release Date: 2026-01-03

## Overview

This release replaces GPL-2.0 licensed external dependencies in the similarity package with native Go implementations. Downstream consumers can now use gofulmen with fully MIT/Apache-2.0 compatible dependency trees.

## Key Changes

- Native Jaro-Winkler implementation (`foundry/similarity/jaro_winkler.go`).
- Native unrestricted Damerau-Levenshtein implementation with proper transposition handling.
- Removed external dependency for clean SBOM (`make license-audit` passes).
- Added `license-audit` to `make check-all` to prevent future license regressions.
- Added 58 golden test cases for algorithm verification.

## Testing & Validation

- `make check-all` (now includes license-audit)
- `make license-audit`
- All Crucible fixture tests pass
- All golden tests pass
