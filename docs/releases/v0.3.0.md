# gofulmen v0.3.0 – Crucible v0.4.1 sync + similarity module promotion

Release Date: 2026-01-06

## Overview

This release syncs Crucible v0.4.1 which promotes the similarity module from a foundry sub-package to a standalone module. The module registry schema (v1.1.0) now includes `weight` and `default_inclusion` fields to support feature-gating in downstream consumers.

## Key Changes

- Updated Crucible to v0.4.1 (`go.mod` and embedded assets).
- Similarity fixtures and schemas moved from `library/foundry/` to `library/similarity/`.
- Module schema v1.1.0 synced with new fields: `weight` (light/heavy), `default_inclusion` (bool), per-language `notes`.
- Signals catalog now contains 9 signals (new signal added in Crucible v0.4.x).
- Test fixture paths updated to new locations.

## Breaking Changes

Synced content paths changed for similarity:

| Old Path | New Path |
|----------|----------|
| `config/crucible-go/library/foundry/similarity-fixtures.yaml` | `config/crucible-go/library/similarity/fixtures.yaml` |
| `schemas/crucible-go/library/foundry/v2.0.0/similarity.schema.json` | `schemas/crucible-go/library/similarity/v2.0.0/similarity.schema.json` |
| `docs/crucible-go/standards/library/foundry/similarity.md` | `docs/crucible-go/standards/library/similarity/similarity.md` |

Consumers referencing synced files directly will need to update paths. The Go API (`foundry/similarity` package) is unchanged.
