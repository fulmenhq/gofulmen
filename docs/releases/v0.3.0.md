# gofulmen v0.3.0 – Crucible v0.4.2 sync + canonical URI resolution

Release Date: 2026-01-07

## Overview

This release syncs Crucible v0.4.2 which establishes the Canonical URI Resolution Standard. All schema `$id` values now use module-qualified URIs (`schemas.fulmenhq.dev/crucible/...`). The schema resolver in `schema/validator.go` has been updated to explicitly handle only crucible-module schemas.

## Key Changes

- Updated Crucible to v0.4.2 (`go.mod` and embedded assets).
- All ~63 schemas updated with `crucible/` module prefix in `$id`.
- Schema resolver (`localLoader.Load()`) now rejects non-crucible modules with clear error.
- New Fixture Standard for test infrastructure repositories.
- Similarity fixtures and schemas moved from `library/foundry/` to `library/similarity/`.
- Module schema v1.1.0 synced with new fields: `weight`, `default_inclusion`, per-language `notes`.

## Breaking Changes

### Schema $id URIs

All crucible-hosted schemas now use module-qualified URIs:

```
# Old (v0.4.1 and earlier)
https://schemas.fulmenhq.dev/<topic>/<version>/<filename>

# New (v0.4.2+)
https://schemas.fulmenhq.dev/crucible/<topic>/<version>/<filename>
```

### Removed Schemas

| Schema Group                              | Reason                        | New Location      |
| ----------------------------------------- | ----------------------------- | ----------------- |
| `schemas/enact/*` (11 files)              | Moved to enacthq organization | enacthq crucible  |
| `schemas/config/goneat/*` (5 files)       | Goneat-owned schemas          | goneat repository |
| `schemas/tooling/goneat-tools/*` (1 file) | Goneat-owned schemas          | goneat repository |

### Similarity Path Changes

| Old Path                                                            | New Path                                                               |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `config/crucible-go/library/foundry/similarity-fixtures.yaml`       | `config/crucible-go/library/similarity/fixtures.yaml`                  |
| `schemas/crucible-go/library/foundry/v2.0.0/similarity.schema.json` | `schemas/crucible-go/library/similarity/v2.0.0/similarity.schema.json` |

The Go API (`foundry/similarity` package) is unchanged.
