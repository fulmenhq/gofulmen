# gofulmen v0.3.2 – Fulencode module + JSON Schema meta-draft support

Release Date: 2026-01-28

## Overview

This release introduces the **fulencode** module—a canonical encoding/decoding library with built-in security protections—and expands JSON Schema validation to support all drafts from Draft-04 through Draft-2020-12. Go toolchain updated to 1.25.5 for vulnerability remediation.

## Key Changes

### New: Fulencode Module

The `fulencode/` package provides canonical encoding operations across the Fulmen ecosystem:

- **Encode**: Base64/Base64URL/Base64-raw, Base32/Base32hex, Hex + UTF-8/UTF-16LE/UTF-16BE/ISO-8859-1/CP1252/ASCII
- **Decode**: All formats with expansion ratio limits, max size protection, checksum verification
- **Detect**: BOM detection, UTF-16 null-pattern heuristic, UTF-8 validation, confidence scoring
- **Normalize**: NFC/NFD/NFKC/NFKD + `text_safe` profile (control char rejection, bidi/zero-width filtering, combining mark limits)
- **BOM Helpers**: `DetectBOM`, `RemoveBOM`, `AddBOM`

Security protections are enabled by default:

- Expansion ratio limits (10x default) prevent encoding bombs
- Max decoded size (100MB default) prevents memory exhaustion
- `text_safe` normalization rejects control characters, bidi controls, and zero-width characters

Uses Crucible SSOT enums via `github.com/fulmenhq/crucible/fulencode` for cross-language consistency.

### New: JSON Schema Meta-Draft Support

Schema validation now supports all JSON Schema drafts end-to-end:

| Draft         | Status                            |
| ------------- | --------------------------------- |
| Draft-04      | Supported                         |
| Draft-06      | Supported                         |
| Draft-07      | Supported (existing)              |
| Draft-2019-09 | Supported                         |
| Draft-2020-12 | Supported (existing, recommended) |

Updated `schema/validator.go` loader resolves json-schema.org metaschemas offline for all drafts.

### Updated: Go Toolchain & Providers

- **Go 1.25.5** – Addresses stdlib vulnerabilities present in Go 1.25.1
- **golang.org/x/mod v0.32.0** – Updated from v0.30.0
- **golang.org/x/text v0.33.0** – Updated from v0.30.0

### Updated: Crucible v0.4.9

## Usage Example

```go
import "github.com/fulmenhq/gofulmen/fulencode"

// Encode bytes to base64
result, _ := fulencode.Encode(data, fulencode.BASE64, nil)
fmt.Println(result.Data)

// Decode with security limits
decoded, _ := fulencode.DecodeString(encoded, fulencode.BASE64, &fulencode.DecodeOptions{
    MaxDecodedSize:    100 * 1024 * 1024,  // 100MB limit
    MaxExpansionRatio: 10.0,                // Bomb protection
})

// Detect encoding with confidence
detection, _ := fulencode.Detect(unknownBytes, nil)
fmt.Printf("Encoding: %s (%.0f%% confidence)\n", *detection.Encoding, detection.Confidence*100)

// Normalize text safely
normalized, _ := fulencode.Normalize(userInput, fulencode.TEXT_SAFE, nil)
```
