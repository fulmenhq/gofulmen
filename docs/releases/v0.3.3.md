# gofulmen v0.3.3 – Control-plane hardening + diagnostics primitives

Release Date: 2026-02-04

## Overview

This release hardens the `signals` HTTP admin endpoint and Prometheus exporter auth for control-plane usage, and adds small diagnostics primitives (env var alias/conflict reporting, sensitive-key masking) to reduce duplication across Fulmen templates.

## Key Changes

### signals: AllowedSignals allowlist

`signals.HTTPConfig` adds `AllowedSignals []string` to restrict which signals may be requested via `signals.HTTPHandler`.

- If `AllowedSignals` is nil/empty: existing behavior is preserved.
- If configured: requests for non-allowlisted signals return HTTP 400.

### signals: Do not trust client grace period by default

`signals.HTTPConfig` adds `AllowClientGracePeriod bool`.

- Default: `false`.
- When `false`: client-provided `grace_period_seconds` is ignored.
- When `true`: the handler applies `grace_period_seconds` as a request-scoped context timeout.

### signals + telemetry/exporters: Bearer token auth hardening

Bearer token authentication now:

- Normalizes parsing for common whitespace/casing variants of `Authorization: Bearer <token>`.
- Uses constant-time compare for the token portion.

### config: Env var alias diagnostics (opt-in)

The `config` package adds alias support and conflict diagnostics without breaking `EnvVarSpec`:

- New `config.EnvVarSpecWithAliases` for canonical names + aliases.
- New `config.LoadEnvOverridesWithReport` and `config.LoadEnvOverridesWithEnvelopeAndReport` return:
  - computed overrides
  - which env var name was applied (canonical vs alias)
  - conflict diagnostics when both are set with different values
- Sensitive values are masked by default in diagnostics/envelopes (`[set]`).

### logging: Sensitive key helper

- New `logging.IsSensitiveKey(name string) bool` helper for envinfo/doctor-style masking.

### foundry + crucible: Correct version reporting

- `foundry.GofulmenVersion()` and `crucible.GetVersion()` now prefer runtime build info so downstream binaries report the installed gofulmen version (with a constant fallback).

### Crucible v0.4.10 sync

- Updated embedded Crucible SSOT assets and `go.mod` dependency to `github.com/fulmenhq/crucible v0.4.10`.

## Behavior Change Note

- `signals.HTTPHandler` no longer honors client `grace_period_seconds` by default. If you relied on that behavior, set `AllowClientGracePeriod: true`.
