# gofulmen v0.3.5 – Release hygiene, appidentity precedence, and dependency refresh

Release Date: 2026-05-12

## Overview

This patch release tightens gofulmen for downstream consumers before the next API-design cycle. It fixes appidentity discovery precedence for embedded binaries, clears release-blocking high security findings, aligns local and CI formatting/linting behavior, and updates the planned v0.3.5 dependency wave.

The previously discussed config utility primitive exports are not part of v0.3.5. They are deferred to v0.3.6 so the API can be designed around confirmed downstream needs and the semantics can be pinned down before export.

## Key Changes

### appidentity: embedded identity precedence

Embedded application identity now takes precedence over CWD and executable-directory ancestor discovery. This prevents packaged binaries from accidentally adopting a nearby checkout's `.fulmen/app.yaml` when running from a foreign working directory.

Explicit path loading and `FULMEN_APP_IDENTITY_PATH` remain authoritative.

### Security hardening

Release-blocking high findings were cleared through targeted hardening:

- Checked ZIP size conversions.
- Permission-mode normalization.
- Validated path and binary resolution.
- CRC byte serialization helpers.
- Additional tests for archive path safety.

### CI and tooling alignment

- Updated CI to use the Fulmen toolbox runner.
- Kept the external installation test active for pull requests.
- Aligned root `.yamlfmt` and `.yamllint` behavior with goneat formatting rules.
- Regenerated and installed goneat hooks without guardian browser interception as the repository moves away from direct-push safeguards.
- Documented local/container format and lint alignment workflow in `docs/GONEAT.md`.
- Moved longer Make recipes into helper scripts to reduce lint churn while preserving existing Make targets.

## Consumer Impact

No public API migration is required for v0.3.5.

Consumers that embed appidentity data in shipped binaries should see safer default identity resolution: embedded identity data wins over ambient repository discovery unless callers explicitly provide an identity path.

## Deferred Work

Config utility primitive exports are deferred to v0.3.6. Before exporting these helpers, the release team will pin down mutating versus non-mutating merge semantics, `map[string]any` scope, slice-copy behavior, nil handling, and whether the API belongs in `config` or a lower-level collection package.
