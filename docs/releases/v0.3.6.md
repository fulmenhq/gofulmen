# gofulmen v0.3.6 – Configuration, validation, and archive reliability

Release Date: 2026-09-21

## Overview

This patch release adds focused configuration, validation, and build identity APIs while tightening archive checksum handling. It also refreshes the project tooling and dependency floor.

## Key Changes

### Configuration primitives

The `config` package now provides non-mutating helpers for supported configuration value graphs:

- `config.MergeMaps` recursively merges objects, replaces arrays, and returns an error for unsupported or cyclic values.
- `config.DeepCopyMap` returns a deep copy and returns an error for unsupported or cyclic values.

Both helpers leave caller-owned maps and slices unchanged.

### Offline schema validation

Schema instance validation now supports offline file-backed inputs with `file://` references and configurable reference directories.

### Host binary identity

The new `buildinfo` package resolves host binary identity from explicit build stamps. `Resolve` does not fall back to process environment values.

### Archive reliability

- Unsupported fulpack checksum selections are rejected.
- Plain gzip archive creation uses compression level 6 consistently.

### Tooling and dependencies

- goneat v0.6.0 and CI runner `goneat-tools-runner-glibc:v0.5.6`.
- Crucible v0.4.19 and refreshed direct dependencies.
- `golang.org/x/text` v0.41.0 for GO-2026-5970.
- Go 1.25 library floor.

## Consumer Impact

No public API migration is required for v0.3.6. Consumers can use the new configuration helpers when their values fit the documented supported graph.
