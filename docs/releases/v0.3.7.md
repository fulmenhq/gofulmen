# gofulmen v0.3.7 – Go 1.26.10 security floor

Release Date: unreleased

## Overview

This patch raises the library Go floor to 1.26.10 for CVE-2026-111943 /
GO-2026-6809 (`crypto/x509`). It also moves local and CI tooling to goneat
v0.6.5, digest-pins the Fulmen toolbox runner at v0.5.12, pins gosec at
v2.29.0, and pins golangci-lint at v2.14.0. Git hooks run without guardian.

## Key Changes

### Go 1.26.10 security floor

- `go.mod` `go` directive: 1.26.9 → 1.26.10.
- CVE-2026-111943 / GO-2026-6809 (Medium 6.8): `crypto/x509` Certificate.Verify
  now denylists known-untrustworthy intermediate certificates.
- Go 1.26.9 is no longer acceptable.
- Go 1.27.3 is refused while gosec's latest release remains v2.29.0.
- CI `setup-go` and the fail-closed toolchain gate require exact Go 1.26.10.

### Tooling

- goneat v0.6.0 → v0.6.5 (`Makefile` `GONEAT_VERSION`).
- CI runner `goneat-tools-runner-glibc` digest-pinned at
  `:v0.5.12@sha256:616a4b5361d2cf7d32ac32496d58e9c288660d5606f0a27efdbf56e3a462ab2d`.
- External installation test Go version: 1.26.10.
- golangci-lint v2.14.0 (`Makefile` `GOLANGCI_LINT_VERSION` and
  `.goneat/tools.yaml`).
- gosec v2.29.0 in `.goneat/tools.yaml`.
- Git hooks generated without guardian.

### Platform note

goneat v0.6.5 has no `darwin/amd64` archive. Intel macOS stays on goneat v0.6.1.

## Consumer Impact

Consumers must use Go 1.26.10 or newer. No public API migration is included.
Crucible remains v0.4.19.

## Testing & Validation

- `go version` reports `go1.26.10`
- `make fmt && git diff --exit-code`
- `make test`
- `make lint`
- `go build ./...`
